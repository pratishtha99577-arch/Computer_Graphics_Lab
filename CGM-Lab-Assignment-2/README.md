# Computer Graphics Lab – Assignment 2

## DDA Line Drawing Algorithm

### Objective
To implement the Digital Differential Analyzer (DDA)
algorithm for drawing a straight line.

### Technologies Used
- C++
- SDL2
- GCC (MinGW64)
- Visual Studio Code

### Algorithm
1. Accept starting and ending coordinates.
2. Calculate dx and dy.
3. Calculate the number of steps.
4. Calculate X and Y increments.
5. Plot pixels using the calculated increments.
